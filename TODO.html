    How to use

    1. Add: type a task in the top box and press Enter or tap Add.
    2. Complete: tick the box next to a task. Use Mark all done to tick everything at once.
    3. Edit: double-click a task to change it. Enter saves, Esc cancels.
    4. Reorder: press and drag the ⋮⋮ grip on a task, then drop it where you want it.
    5. Slogan: double-click the line in the teal bar to write your own.
    6. Filter: switch between All, Active, Completed and Trash above the list.
    7. Trash: deleting an unfinished task sends it to Trash. Restore it or delete it forever there.
    8. Backup: Export JSON downloads your tasks. Import file loads a JSON file or a text file with one task per line.
    9. Privacy: everything is saved in this browser only. Clearing site data removes it.
